FEATURES

安全性と利便性を両立する設計

アカウントの安全を最優先にしつつ、確実でストレスフリーな通知体験を提供します。

ゼロ・トラフィック原則

艦これ運営サーバーへの自発的なAPIリクエストは一切行いません。ブラウザ内の通常通信を受動的に読み取るだけのため、BANリスクを極限まで低減します。

Windows デスクトップ常駐通知

Rust製超軽量デーモンがSSEストリームでプッシュ通知を受信し、OSネイティブのトースト通知を発行。専用の「艦これ 通知管理」ダッシュボードGUIで残り時間もひと目で把握できます。

Cloudflare Workers 連携

PCをスリープさせたりブラウザを閉じても安心。Durable Objectsの正確なアラーム機能がサーバー側で時間を刻み、指定時刻に確実にプッシュします。

Discord / Telegram 対応

Discord Webhook や Telegram Bot とシームレスに連携。PCから離れていても、スマートフォンやスマートウォッチでいつでも艦隊状況を受信できます。

遠征・入渠・建造の完全網羅

全艦隊の遠征完了タイマー、入渠ドックの修復完了、工廠の建造終了をリアルタイムで同期・スケジュール化します。

泊地修理 ＆ 疲労度（cond）管理

泊地修理の20分サイクル確定判定や、cond値3分ごとの自然回復（上限49）を拡張機能側で高精度に算出。出撃準備の無駄を徹底的に省きます。

ARCHITECTURE

高信頼・3層分散アーキテクチャ

拡張機能が高精度に算出し、中央サーバーがスケジューリング、マルチデバイスへ即時配信します。

LAYER 1

拡張機能（Edge）

ゲーム通信を受動パース。遠征・入渠・泊地修理・疲労回復の完了時刻を高精度に算出し、確定スケジュールを中央サーバーへ登録します。

LAYER 2

中央サーバー（Cloudflare）

Single Source of Truth。D1での永続化、Durable Objectsのアラーム機能、SSEイベントストリームによるリアルタイムプッシュ配信を制御します。

LAYER 3

通知末端（Terminal）

Windows デスクトップ常駐デーモン（トースト通知 ＆ GUI）や Discord / Telegram へ即時配信。どこにいても最新状況が届きます。

GET STARTED

超かんたん3ステップ導入

オンラインインストーラーを実行するだけで、サーバー構築からデスクトップ通知まで自動セットアップ！

01

オンラインインストーラーを実行

お使いのOSに合わせて超軽量オンラインインストーラーを実行します。画面の案内に従って Cloudflare API トークンと通知先（Discord Webhook 等）を入力するだけで、GitHubから最新のバイナリ・拡張機能を自動取得し、Cloudflare Workers の構築・デプロイまで全自動で行われます。

【Windows】kancolle-notify-setup.exe をダウンロードして実行
【Linux】curl -fsSL https://raw.githubusercontent.com/Ikumyon/kancolle-notify/main/installer/install.sh | bash
02

ブラウザ拡張機能を読み込み

Chrome または Edge の拡張機能管理画面（chrome://extensions）を開き、右上の「デベロッパーモード」をONにします。「パッケージ化されていない拡張機能を読み込む」をクリックし、インストーラーが自動配置した拡張機能フォルダを選択します。

インストーラーを実行した場所にある kancolle-notify/extension フォルダを選択

※サーバーURLや接続設定はインストーラーにより自動構成されているため、面倒な初期設定は不要です。

03

プレイ開始 ＆ デスクトップで進捗確認

バックグラウンドで Rust 製の超軽量デーモンが常駐し、完了時刻に OS ネイティブのトースト/D-Bus通知や Discord へお知らせします。アプリメニューの「艦これ 通知管理」から、遠征や入渠の残り時間をリアルタイムに確認することも可能です！

アプリメニュー ➔ 「艦これ 通知管理」でタイマー進捗一覧を表示
上級者・開発者向け：手動デプロイ手順はこちら

インストーラーを使わずに CLI から独自に構築したい場合は、リポジトリをクローンして以下のコマンドで Cloudflare Workers へデプロイ可能です：

cd server && npm install && npx wrangler deploy

デプロイ後に払い出された Workers URL を拡張機能のオプション画面およびデスクトップ設定ファイル（config.json）に設定してください。

FAQ

よくあるご質問

導入前の気になる点や安全性についてお答えします。

BANされるリスクはありますか？

本システムは「ゼロ・トラフィック原則」に基づき設計されており、拡張機能から艦これ運営サーバーに対して自発的な通信やAPI呼び出しを行うことは一切ありません。ブラウザが通常受け取っているゲームパケットを受動的に読み取るだけのため、運営サーバー側から通常のブラウザプレイと判別されることはありません。

パソコンの電源を切ったりスリープしても通知されますか？

はい、通知されます。観測された遠征や入渠の完了時刻は中央サーバー（Cloudflare Workers Durable Objects）に即座に登録されるため、PCをシャットダウンしてもサーバー側が指定時刻に自動でDiscordやTelegramに通知を送信します。

サーバーの維持費（Cloudflareの利用料）はかかりますか？

個人利用の範囲であれば、Cloudflare Workers / D1 の無料枠（Freeプラン）で十分に収まる設計となっています。

専用ブラウザや外部支援ツールでも利用・併用できますか？

はい、Chrome拡張機能の追加・読み込みに対応している専用ブラウザであれば、本拡張機能をそのまま導入してご利用いただけます。

また、ブラウザで艦これを起動し、裏でネットワーク監視・ローカルプロキシ中継を行うタイプの外部支援ツールをお使いの場合でも、ブラウザ側に本拡張機能をインストールして併用することで問題なく動作します（受動監視設計のため相互に通信や動作が競合することはありません）。

※拡張機能の直接追加に対応していない専用ブラウザ（内蔵ウィンドウ完結型）の中には直接インストールできませんので、その場合はChromeやEdge等の対応ブラウザ環境をご利用ください。

オンラインインストーラーは何をしてくれますか？

インストーラー自身はわずか数MBの超軽量設計で、実行時にGitHubから最新版のWindowsデスクトッププログラム（Rustデーモン＆通知管理GUI）、ブラウザ拡張機能、サーバーコードを取得します。さらにユーザーのCloudflareアカウントへの自動デプロイと拡張機能の初期設定ファイルの自動生成までをワンストップで行うため、黒い画面（CLI）を触ることなく簡単に導入いただけます。

デスクトップ通知（トースト通知）や通知管理アプリの常駐負荷は重くないですか？

バックグラウンドで待機するデーモンは Rust で開発されており、メモリ使用量は数MB〜十数MB程度と極めて軽量です。また、定期的な重いポーリングを行わずサーバーからの SSE（Server-Sent Events）プッシュ通知を受信する設計のため、PCのCPU負荷やネットワークトラフィックをほぼ消費しません。
