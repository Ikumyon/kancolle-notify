◷通知・タイマー管理01

kancolle-notify

遠征・入渠・疲労回復などのタイマーを管理。デスクトップ通知に加え、クラウド経由で Discord や Telegram にお知らせします。

  • 遠征・入渠・建造・泊地修理・疲労回復に対応
  • Windows / Linux のデスクトップ通知
  • PC を閉じた後も、クラウドから通知
詳しい機能説明

こんなときに

遠征の帰投まで別の作業をしたいときや、入渠の終了をスマートフォンで知りたいときに。通知管理画面では、艦隊やドックの残り時間をまとめて確認できます。

通知が届くまで

ブラウザ拡張機能がゲーム通信からタイマー情報を読み取り、Cloudflare に終了時刻を送信します。クラウド側が時刻を管理するため、送信済みのタイマーはブラウザや PC を閉じた後も Discord・Telegram に通知できます。

Windows・Linux のデスクトップ通知を受けるには、PC と常駐プログラムを起動しておきます。ゲーム内で操作を変更した場合、その情報が反映されるには拡張機能が動作している必要があります。

導入前に用意するもの

Chrome / Edge などの対応ブラウザ、Cloudflare アカウントと Workers・D1 を編集できる API トークンを用意します。Discord を使う場合は通知先の Webhook、Telegram を使う場合は Bot の設定も必要です。

セットアップをダウンロード

Windows 用 · kancolle-notify-setup.exe

配布先準備中

別の OS 用も、上のボタンから選べます。

Windows の導入手順
  1. kancolle-notify-setup.exe をダウンロードして実行します。
  2. ウィザードに従って Cloudflare API トークンと通知先を設定します。
  3. ブラウザの拡張機能管理画面でデベロッパーモードを有効にし、インストール先の extension フォルダを読み込みます。
  4. 「艦これ 通知管理」を開いて、タイマーを確認します。
Linux の導入手順
  1. install.sh をダウンロードします。
  2. 保存先のフォルダで端末を開き、次のコマンドを実行します。
    bash install.sh
  3. 対話形式の案内に従って Cloudflare API トークンと通知先を設定します。
  4. ブラウザの拡張機能管理画面でデベロッパーモードを有効にし、インストール先の extension フォルダを読み込みます。

インストーラーはインターネット接続と bash・curl・tar・unzip を使用します。

▤配信・情報表示02

Kancolle Stream Overlay

タイマーや出撃情報をブラウザ上に表示する拡張機能。配置や表示内容を調整して、自分の配信に合う画面をつくれます。

  • 海域・難易度・ドロップ数などの情報表示
  • パネルの移動・リサイズとレイアウトの保存
  • 手動タイマーと通知側のクラウドタイマー連携
詳しい機能説明

配信中に伝えたい情報をまとめる

出撃先の海域や難易度、攻略の進行状態、ドロップ数、自由記述などを画面に表示できます。見せたい内容に合わせて、行・列・カードを追加したり、表示形式を調整したりできます。

配置とタイマーを自分の使い方に

情報パネルとコントロールパネルは、ドラッグで移動・リサイズできます。設定は保存されるため、次回も同じレイアウトを使えます。手動タイマーは時間指定やプリセット、完了通知に対応しています。

必要な連携だけ追加

Cloudflare 連携を設定すると、通知側で管理している遠征・入渠・疲労回復などのタイマーを選んで表示できます。BGM 名や戦果情報を受け取り、表示に反映する機能も備えています。BGM 表示には、KCO-title-fetcher と KCO-relay の両方を追加して利用します。

まずは表示と手動タイマーから使い始め、クラウドタイマーの取得が必要になったら通知側との連携を設定できます。

ブラウザ拡張機能をダウンロード

Windows / Linux 共通 Chrome・Edge

展開して読み込むブラウザ拡張機能

配布先準備中

Cloudflare 連携は、必要に応じて設定できます。

オーバーレイの導入手順
  1. 配布ファイルをダウンロードして展開します。
  2. Chrome の chrome://extensions、または Edge の edge://extensions を開きます。
  3. 「デベロッパーモード」を有効にし、「パッケージ化されていない拡張機能を読み込む」を選びます。
  4. 展開したフォルダ内の manifest.json があるフォルダを選択します。
  5. 設定画面から、表示内容やレイアウトを調整します。

オーバーレイの BGM 表示用補助ツール

BGM 名を表示する場合は、KCO-title-fetcher と KCO-relay をセットで導入します。title-fetcher が動画共有サイトのタイトルを取得し、relay がオーバーレイへ渡します。どちらか一方だけでは BGM 表示の連携はできません。

動画共有サイト→KCO-title-fetcher
タイトルを取得→KCO-relay
データを中継→オーバーレイ

KCO-title-fetcher

BGM 名として表示するタイトルを取得。

詳しい機能説明

動画共有サイトのタイトルを取得する JavaScript 製のツールです。タイトル取得時にサーバーへ負荷をかけないことを特徴としています。

担当する役割

オーバーレイの BGM 表示に使う動画タイトルを取得します。取得したタイトルをオーバーレイに届けるため、KCO-relay も一緒に導入してください。

BGM 表示用 · データ中継04

KCO-relay

取得したタイトルをオーバーレイへ中継。

詳しい機能説明

拡張機能どうしでデータを受け渡すための Python 製ツールです。BGM 表示では、KCO-title-fetcher が取得したタイトルをオーバーレイへ中継します。title-fetcher と同時に導入して利用します。

文字の読み取りも補助

中継機能に加えて OCR にも対応しています。OCR は画像内の文字を読み取る機能です。受け渡す情報や読み取り対象に合わせて利用します。

Cloudflare 連携の設定手順
  1. 通知側のセットアップを完了し、Worker URL と認証トークンを用意します。
  2. オーバーレイの設定画面で「タイマー」タブを開き、「Cloudflare連携」を ON にして入力・保存します。

導入前によくある疑問

4つすべてを入れる必要がありますか？

使いたい機能に合わせて選んでください。通知を使うなら kancolle-notify、画面表示や手動タイマーを使うならオーバーレイから始められます。オーバーレイで BGM 名も表示する場合は、KCO-title-fetcher と KCO-relay の両方を追加してください。この2つは BGM 表示機能のための補助ツールです。

PC を閉じても通知されますか？

通知側から Cloudflare へ送信済みのタイマーは、設定した Discord・Telegram へ通知できます。PC 上のデスクトップ通知とオーバーレイ表示には、PC と各プログラムの起動が必要です。

Windows から Linux 用をダウンロードできますか？

できます。通知のダウンロード欄で「Linux」に切り替えると、セットアップ用 .sh と Linux の導入手順を表示します。Linux から Windows 用 .exe を選ぶこともできます。

「配布先準備中」と表示されるのはなぜですか？

現在、このページのダウンロードリンクを準備しています。配布先が設定されると、各ツールのダウンロードボタンが利用できるようになります。

このツールについて

本ツールは非公式のファンメイドツールです。DMM GAMES および「艦これ」運営とは関係ありません。通知機能はブラウザが受信したゲーム通信を読み取って動作します。クラウド通知には Cloudflare の設定が必要です。
