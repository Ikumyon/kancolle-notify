## ツールの概要

**KCO title fetcher** は、YouTube やニコニコ動画で再生中のタイトルを取得し、ローカル環境の KCO Relay へ送信するためのブラウザ拡張機能です。
Kancolle Stream Overlay と組み合わせることで、配信画面上に現在のBGM名を表示できます。

## 主な機能

YouTube / ニコニコ動画のページから現在の再生タイトルを取得し、`localhost` / `127.0.0.1` の中継先へ送信します。

拡張機能内では、次に再生する動画リストも管理できます。
YouTubeのプレイリストやミックスリストのパラメータを外し、単体動画として扱いやすくする設定もあります。

## 導入手順

1. ソースコードをダウンロードして展開します。
2. Chrome / Edge の拡張機能管理画面を開きます。
3. **デベロッパーモード** を有効にします。
4. **パッケージ化されていない拡張機能を読み込む** から、この拡張機能のフォルダーを選択します。
5. KCO Relay を起動し、Kancolle Stream Overlay 側でBGM表示を有効にします。

## 対応サイト

- YouTube
- ニコニコ動画

## 関連ツール

- **KCO Relay**: 取得したタイトル情報をローカルで受け取り、中継します。
- **Kancolle Stream Overlay**: 中継されたBGMタイトルを配信画面へ表示します。
