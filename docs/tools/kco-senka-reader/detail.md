## ツールの概要

**KCO 通常戦果リーダー** は、提督経験値の増加量から通常戦果を推計し、Kancolle Stream Overlay の情報パネルへ送るための補助ブラウザ拡張です。
KC3の換算式を参考にした独立実装で、KC3本体の導入は不要です。

## 主な機能

提督経験値差分をもとに、経験値増加 × 7 / 10000 で通常戦果を換算します。
日本時間2:00・14:00など、KC3に合わせた締め判定を行い、算出済みの戦果値を Kancolle Stream Overlay の戦果カードへ送ります。

集計状態は拡張機能のローカルストレージに保存します。

## 導入手順

1. この拡張機能を Damecon または Chrome / Edge に、独立した拡張として読み込みます。
2. Kancolle Stream Overlay も読み込み、ゲームページを再読み込みします。
3. ゲームタブの開発者ツールを開いたまま、母港を表示します。
4. オーバーレイの情報パネルに「戦果」カードを追加します。
5. オーバーレイ設定の戦果カードで、戦果リーダーが有効に読み込まれていることを確認します。

## 注意点

- ゲームサーバーへ追加リクエストは送信しません。DevTools APIで、ブラウザが受信した通信レスポンスを観測します。
- 初回観測時の提督経験値を基準にするため、導入前の獲得分は復元できません。
- EO、任務のボーナス戦果、引継ぎ戦果は含みません。
- 開発者ツールを閉じると観測を停止します。

## 動作確認
