# ビルド・重い処理の実行に関する禁止ルール

1. **時間のかかるビルド処理の勝手な実行禁止**:
   - `pyinstaller` や `cargo build --release`、その他時間のかかるパッケージング・本番ビルドコマンドは、**ユーザーから「ビルドしてください」「実行してください」等の明確な指示がない限り、AI側で勝手に実行してはならない**。
   - 変更の確認・検証が必要な場合でも、構文チェック（`python -m py_compile` や `cargo check` などの軽量な静的チェック）にとどめ、重いビルド処理はユーザー自身が実行できるように手順を提示すること。

2. **時間のかかる処理（ビルド・CI/CD・デプロイ等）の完了待ち・ポーリングの絶対禁止**:
   - コマンド実行やGitプッシュなど、外部やバックグラウンドで時間のかかる処理をトリガーした後は、**AI側でタイマーを回したり、ポーリングして結果を待ったりせず、トリガーした時点で即座に手を引いてターンを終了すること**。
   - 「必要な作業・トリガーは完了しました。あとは数分待てば完了する見込みです」と引き渡し、結果の確認や次のアクションは必ずユーザーからの報告・指示を待つこと。

3. **自律的な先回り実行の制限**:
   - ユーザーから「ok」や計画の承認を得た場合であっても、許可された範囲（コードの編集・軽量な検証）のみを実施し、ビルドやデプロイなどの重い処理まで先回りして巻き込んで実行してはならない。

4. **プロセスの後始末（クリーンアップ）**:
   - 動作確認やテスト等でプロセスを起動した場合は、確認終了後に必ずプロセスを停止し、プロセス残留やファイルロックを残さないこと。
