# 通知アイコンのカスタマイズ

[← デスクトップREADMEに戻る](../README.md)

このフォルダ（`icons/`）内の画像ファイルを差し替えることで、デスクトップ通知に表示されるアイコンをお好みの画像に変更できます。

---

## 対応ファイル名と通知種別

| ファイル名 | 通知種別 | 説明 |
| :--- | :--- | :--- |
| `expedition.png` | **遠征帰投** | 艦隊が遠征から帰投した時の通知 |
| `repair.png` | **入渠完了** | 入渠ドックでの修復が完了した時の通知 |
| `build.png` | **建造完了** | 工廠での建造が完了した時の通知 |
| `fatigue.png` | **疲労回復** | 艦娘の疲労（コンディション）回復通知 |
| `akashi.png` | **泊地修理** | 明石による泊地修理（20分タイマー）通知 |
| `manual.png` | **手動タイマー** | ユーザーが手動で設定したタイマー完了通知 |
| `default.png` | **基本・共通** | 上記以外の通知やフォールバック用アイコン |
| `app.png` / `app.ico` | **アプリアイコン** | WindowsのAUMID登録および全体の代表アイコン |

---

## 推奨画像フォーマット

* **形式**: PNG形式（`.png`）推奨。`.ico`, `.jpg` にも対応しています。
* **サイズ**: **128 x 128 px** 〜 **256 x 256 px** の正方形画像を推奨します。
* **背景**: 透過PNGを推奨します。

---

## 変更の反映

* 画像ファイルをこのフォルダに保存・上書きするだけで、**次回の通知から即座に反映**されます。
* アプリやデーモンの再起動は不要です。
