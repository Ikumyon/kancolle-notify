# カスタム通知音（音声ファイル）の設定

[← デスクトップREADMEに戻る](../README.md)

このフォルダ（`sounds/`）にお好みの音声ファイル（`.wav`）を配置することで、通知時にオリジナルの効果音や艦娘のボイスを再生できます。

---

## 対応ファイル名と通知種別

| ファイル名 | 通知種別 | 説明 |
| :--- | :--- | :--- |
| `expedition.wav` | **遠征帰投** | 艦隊が遠征から帰投した時の通知音 |
| `repair.wav` | **入渠完了** | 入渠ドックでの修復が完了した時の通知音 |
| `build.wav` | **建造完了** | 工廠での建造が完了した時の通知音 |
| `fatigue.wav` | **疲労回復** | 艦娘の疲労（コンディション）回復時の通知音 |
| `akashi.wav` | **泊地修理** | 明石による泊地修理完了時の通知音 |
| `manual.wav` | **手動タイマー** | ユーザーが手動で設定したタイマー完了時の通知音 |
| `default.wav` | **共通デフォルト** | 個別ファイルがない場合の共通音、および基本通知音 |

---

## 音声フォーマット仕様

* **ファイル形式**: **WAV形式 (`.wav`)**
* **推奨スペック**: 非圧縮リニアPCM (16bit)、サンプリングレート 44.1kHz または 48kHz、モノラル/ステレオ
* **推奨の長さ**: **1秒〜5秒程度**（長時間の音声は通知後もしばらく鳴り続けます）
* ※MP3やAACなどの圧縮形式には直接対応していません。あらかじめWAV形式に変換して配置してください。

---

## 再生ルールと優先順位

1. **個別通知音の優先**:
   通知の種類に応じたファイル（例: 遠征なら `expedition.wav`）が存在すれば、それを最優先で再生します。
2. **共通デフォルト音へのフォールバック**:
   個別ファイルが存在せず、`default.wav` が存在する場合は、`default.wav` を再生します。
3. **OS標準通知音**:
   該当する音声ファイルがこのフォルダに置かれていない場合は、従来通りのOS標準通知音（Windows標準トースト音 / Linux標準通知音）が鳴ります。
4. **サウンド設定**:
   設定画面等でサウンドがOFFになっている場合は、音声ファイルがあっても再生されません。

---

## 変更の反映

* 音声ファイルをこのフォルダに保存・上書きするだけで、**次回の通知から即座に反映**されます。
* アプリやデーモンの再起動は不要です。
